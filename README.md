# ✈️ 스마트 여행 플래너 635 (Travel Planner 635)

동행인과 함께 실시간으로 일정을 공유하고, 코스·예산·체크리스트를 관리할 수 있는 Apple Liquid Glass 감성의 모바일 퍼스트 여행 일정 플래너 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **Apple Liquid Glass UI & 모바일 퍼스트 UX (`impeccable`)**:
   - 눈이 편안한 밝은 화면(`light`), WCAG AA 고대비 타이포그래피, iOS `safe-area-inset` 완벽 대응
   - 모든 핵심 버튼·칩·탭·드래그 핸들 최소 터치 영역 `44×44px` 이상 보장
2. **일차(Day) 관리 및 모바일 터치 드래그 앤 드롭**:
   - `전체` / `남은 일정` / `완료` 코스 필터 및 `Day 1`, `Day 2` ... 일차별 코스 분리·추가·삭제
   - **iOS Safari & Android Chrome 터치 드래그 앤 드롭**: 전용 드래그 핸들(`⠿`) 또는 카드 250ms 길게 누르기(Long-press)로 스크롤과 충돌 없이 부드럽게 순서 변경 및 가장자리 자동 스크롤 지원 (필터가 켜진 상태에서도 원본 `pins` ID 매핑으로 정확히 저장)
3. **장소별 할 일 (`localTodos`) & 인라인 이름 클리어(`×`)**:
   - 긴 주소가 이름으로 들어갔을 때 우측 작은 `×` 버튼으로 장소(핀) 삭제 없이 이름만 즉시 비우고 인라인 재입력
   - 장소 카드별 체크리스트(`localTodos`) 관리
4. **예산 및 1/N 정산**:
   - 총 예산(KRW / JPY), 실시간 환율 자동 환산, 1인당 정산(1/N), 일차(Day)별 예산 합계 요약
5. **보안 게이트 · 비밀번호 관리 · 클라우드 무결성 동기화**:
   - **초대 코드·티켓 시스템 완전 제거**: 초기 접속 비밀번호 **`0000`**, 초기 관리자 비밀번호 **`0000`** 적용으로 언제 어디서나 깔끔하게 입장
   - **관리자 권한 모달(`👑` / `⚙️`)**: 접속 비밀번호 단독 변경 및 관리자 비밀번호 변경 지원 (커스텀 비밀번호 등록 시 초기 0000 자동 비활성화)
   - **장소(핀) 무결성 저장**: 장소 추가·수정·삭제·순서변경·메모·체크리스트 즉시 localStorage 반영 및 2~3회 지수 백오프 자동 재시도로 데이터 소실 방지
   - 5회 연속 오류 시 10분 일시 잠금 및 관리자 즉시 해제 지원

## 📱 홈 화면 추가(PWA) 및 단축어 중첩 문제 해결 안내

기존에 아이폰(iOS Safari)이나 안드로이드(Chrome)에서 여러 웹앱을 홈 화면에 추가했을 때 **아이콘이 겹치거나 나중에 만든 앱만 열리는 현상**을 해결하기 위해 고유 앱 식별자(`id: "/?app=travel-planner-635"`, `start_url: "/?app=travel-planner-635"`)와 전용 PNG 아이콘(`/icons/apple-touch-icon-180.png`, `/icons/icon-192.png`, `/icons/icon-512.png`)이 적용되었습니다.

### 1) iOS (Safari) 홈 화면 재등록 방법
1. 아이폰 홈 화면에 기존에 추가해 둔 **이전 여행 플래너 아이콘을 길게 눌러 삭제(북마크 삭제)** 합니다.
2. **설정 → Safari → 고급 → 웹사이트 데이터**에서 해당 도메인 캐시가 남아 있다면 정리하거나, Safari에서 `https://<배포도메인>/?app=travel-planner-635` 주소로 접속합니다.
3. 하단 **공유 버튼(⬆️)** → **홈 화면에 추가**를 누릅니다.
4. 이름이 **`여행플래너635`** 로 표시되는지 확인한 뒤 **추가**를 누르면 기존 다른 웹앱과 겹치지 않고 독립된 앱으로 실행됩니다.

### 2) iOS 「단축어(Shortcuts)」 앱을 사용하는 경우
- 단축어에서 **URL 열기** 액션을 사용할 때 주소를 반드시 고유 쿼리가 포함된 `https://<배포도메인>/?app=travel-planner-635` 로 지정하고, 기존 다른 단축어와 **단축어 이름 및 아이콘을 다르게** 설정하세요.

### 3) Android (Chrome) 홈 화면 재등록 방법
1. 홈 화면의 기존 아이콘을 길게 눌러 **삭제(제거)** 합니다.
2. Chrome에서 사이트 접속 후 우측 상단 메뉴(`⋮`) → **홈 화면에 추가(또는 앱 설치)** 를 선택하면 고유 ID(`/?app=travel-planner-635`) 기준의 독립 웹앱(`여행635`)으로 설치됩니다.

## 🚀 배포 및 환경 설정 (Vercel)

Vercel 대시보드 (`Project Settings` → `Environment Variables`)에서 다음 환경변수를 설정합니다 (`.env.example` 참고).

| 환경변수 이름 | 필수 여부 | 설명 |
| :--- | :---: | :--- |
| `SUPABASE_URL` | **필수** | Supabase 프로젝트 URL (예: `https://xxxx.supabase.co`) |
| `SUPABASE_ANON_KEY` | **필수** | Supabase 익명 공개 API 키 (`anon` `public` key) |
| `ENTRY_DEFAULT_SALT` / `ENTRY_DEFAULT_PBKDF2_HASH` | 선택 | 초기 접속 비밀번호용 커스텀 PBKDF2-SHA512 솔트 및 해시 |
| `ADMIN_MASTER_SALT` / `ADMIN_MASTER_PBKDF2_HASH` | 선택 | 관리자 금고용 커스텀 PBKDF2-SHA512 솔트 및 해시 |
