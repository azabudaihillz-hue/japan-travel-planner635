# ✈️ 스마트 여행 플래너 (Travel Planner)

동행인과 함께 실시간으로 일정을 공유하고, 코스·예산·체크리스트를 관리할 수 있는 Apple Liquid Glass 감성의 여행 일정 플래너 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **Apple Liquid Glass UI**: 눈이 편안한 밝은 화면(`light`), 반투명 글라스 카드(`backdrop-filter: blur(18px)`), 부드러운 반응형 인터페이스
2. **일차(Day) 관리 및 필터**:
   - `전체` / `남은 일정` / `완료` 코스 필터
   - `모든 Day` 및 `Day 1`, `Day 2` ... 일차별 코스 분리 및 동적 일차 추가
   - 드래그 앤 드롭 시 원본 인덱스 매핑 및 하이라이트 드롭 위치 피드백
3. **장소별 할 일 (`localTodos`)**: 장소 카드별 체크리스트 관리 및 인라인 원터치 추가
4. **예산 및 1/N 정산**:
   - 총 예산(KRW / JPY), 실시간 환율 자동 환산, 1인당 정산(1/N)
   - 예산 소진율 프로그레스 게이지 및 **일차(Day)별 예산 합계 요약**
5. **보안 게이트 및 클라우드 동기화**:
   - 시작 페이지 비밀번호 입력 및 PBKDF2 단방향 암호화 인증
   - 비밀번호 5회 오입력 시 IP 자동 차단
   - 관리자 전용 금고(`👑`)에서 허용 비밀번호 추가/삭제 및 차단 IP 관리
   - 매번 난수가 생성되는 **원클릭 보안 초대 링크** 발급 (비밀번호 노출 0%)

---

## 🚀 배포 및 환경 설정 (Vercel)

본 프로젝트는 Vercel Serverless Function 환경을 기반으로 동작합니다.

### 🔑 필수 환경변수 (Environment Variables)

Vercel 대시보드 (`Project Settings` → `Environment Variables`)에서 다음 환경변수를 설정해야 클라우드 실시간 동기화(`/api/sync`)가 정상 작동합니다.

| 환경변수 이름 | 필수 여부 | 설명 |
| :--- | :---: | :--- |
| `SUPABASE_URL` | **필수** | Supabase 프로젝트 URL (예: `https://xxxx.supabase.co`) |
| `SUPABASE_ANON_KEY` | **필수** | Supabase 익명 공개 API 키 (`anon` `public` key) |

> ⚠️ **보안 안내**: 환경변수가 누락되었을 경우 서버리스 함수는 보안을 위해 키 정보를 노출하지 않고 `500 Server configuration missing` 에러를 반환합니다.

## 🎟️ 동행인 입장 방법

1. **비밀번호 직접 입력**: 시작 페이지에서 관리자가 설정한 접속 비밀번호를 입력하고 입장합니다. (기본 비밀번호 또는 관리자 금고에서 추가한 비밀번호)
2. **원클릭 보안 초대 링크**: 관리자가 설정 메뉴에서 생성한 난수 초대 링크(`/#invite=...`)를 클릭하면 비밀번호 입력 없이 즉시 안전하게 입장할 수 있습니다.
